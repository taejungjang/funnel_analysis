# 이커머스 이벤트 로그 기반 퍼널 분석 및 데이터 구조 정의

본 프로젝트는 Google Merchandise Store의 GA4 이벤트 로그 데이터를 활용하여  
사용자의 구매 여정을 분석하고, 데이터 정합성을 확보한 뒤 퍼널 분석을 수행하여  
전환율 개선을 위한 인사이트를 도출한 프로젝트입니다.  

단순 분석에 그치지 않고,이벤트 구조 정의 및 데이터 품질 검증을 통해  
신뢰 가능한 분석 기반을 구축하는 데 중점을 두었습니다.

---

## 1. 분석 배경 및 목적

GA4 이벤트 로그 데이터는 event_name 단위로 수집되기 때문에  
이벤트 간 연결 관계가 명확하지 않아 사용자 행동 흐름을 일관된 기준으로 파악하기 어렵습니다.  

또한 구매 이벤트는 존재하지만 이전 단계 이벤트가 누락되는 등  
데이터 정합성 문제가 발생하여, 이를 그대로 사용할 경우 전환율이 왜곡될 가능성이 있었습니다.  

이에 따라 본 프로젝트에서는  
- 유저 행동 이벤트 구조(퍼널) 정의  
- 로그 데이터 정합성 검증 및 보정(Data QA)  
- 이를 기반으로 한 퍼널 분석 수행  

을 목표로 진행했습니다.

---

## 2. 데이터 개요

- **데이터셋**: `ga4_obfuscated_sample_ecommerce` (GA4 샘플 데이터)  
- **기간**: 2020.11.01 ~ 2021.01.31 (3개월)  
- **주요 컬럼**
  - `event_name`: 사용자 행동 이벤트 (page_view, purchase 등)
  - `user_pseudo_id`: 사용자 식별자 (User 기준 분석)

---

## 3. 데이터 구조 정의 및 정합성 검증

### 3.1 이벤트 퍼널 정의 

사용자의 구매 의사결정 흐름을 기준으로 이벤트를 재구성하여  
다음과 같은 6단계 퍼널을 정의했습니다.

1. Page View (방문)
2. View Item (상품 조회)
3. Add to Cart (장바구니)
4. Begin Checkout (결제 진입)
5. Add Payment Info (결제 정보 입력)
6. Purchase (최종 구매)

---

### 3.2 데이터 전처리 및 구조화

- SQL을 활용하여 GA4 이벤트 로그 데이터를 조회 및 추출  
- 날짜별로 분산된 테이블을 통합하여 분석 가능한 형태로 정리  
- user_pseudo_id 기준으로 데이터를 집계하여 사용자 단위 분석 수행  

---

### 3.3 데이터 정합성 검증 

로그 데이터를 검토하는 과정에서  
**구매 이벤트는 존재하지만 이전 단계 이벤트가 누락된 케이스**를 확인했습니다.

이는 데이터 수집 과정에서 발생한 오류로 판단했으며,  
해당 데이터를 그대로 사용할 경우 퍼널 전환율이 왜곡될 수 있다고 보았습니다.  

따라서 다음과 같은 방식으로 데이터 QA를 수행했습니다.

- 이전 단계 로그가 없는 하위 이벤트 탐지  
- 해당 이벤트를 상위 단계에도 포함시키는 방식으로 보정  
- 퍼널 단계 간 일관된 흐름이 유지되도록 정합성 검증 수행  

이를 통해 **신뢰 가능한 분석 데이터셋을 구축했습니다.**

## 4. 퍼널 분석 결과

| 단계 | 사용자 수 | 전환율 |
|------|----------|--------|
| Page View | 269,821 | - |
| View Item | 61,335 | 22.7% |
| Add to Cart | 16,603 | 27.0% |
| Begin Checkout | 9,717 | 58.5% |
| Add Payment Info | 5,752 | 59.1% |
| Purchase | 4,419 | 76.8% |

- 전체 전환율: **1.6%** (방문 대비 구매)
- 주요 병목 구간: **상품 조회 단계 (22.7%)**

👉 방문 대비 상품 조회로 이어지는 비율이 다른 부분에 비해 낮아  
초기 단계에서 상대적 이탈이 발생하는 것을 확인했습니다.

---

## 5. 유입 경로별 성과 분석

### 가설
유입 경로에 따라 상품 조회 전환율에 차이가 존재할 것이다.

### 분석 방법
- 카이제곱 검정을 통한 통계적 유의성 검증

### 결과

| 채널 | 전환율 |
|------|--------|
| Referral | 24.8% |
| Organic | 22.0% |
| CPC | 20.0% |

- p-value < 0.05 → 통계적으로 유의미한 차이 확인  
- CPC(유료 광고) 유입의 전환율이 가장 낮음

## 6. 액션 플랜

### 1. 랜딩 페이지 최적화
광고 유입 사용자를 메인 페이지가 아닌  
상품 상세 페이지로 직접 연결하여 이탈률 감소

### 2. 개인화 추천 강화
초기 화면에서 사용자 맞춤 상품 추천을 제공하여  
상품 조회 단계로의 전환 유도

### 3. 제품 시장성 점검
상품 조회율 자체가 낮기 때문에  
타겟 고객에 맞는 상품 구성 재검토 필요

---

## 7. 프로젝트를 통해 얻은 인사이트

- 이벤트 로그 데이터는 **구조 정의 없이 바로 분석할 경우 왜곡 가능성 존재**
- 데이터 정합성 검증이 분석 결과의 신뢰도를 결정하는 핵심 요소임을 확인
- 유저 행동 데이터를 기반으로 문제를 정의하고 개선 방향을 도출하는 경험 수행
